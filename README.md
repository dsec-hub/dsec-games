# DSEC Games

The games surface for `games.dsec.club`, currently hosting Flappy Duck and
Codle. It is a thin Next.js client: scores, rounds, and leaderboards are decided
only by `dsec-api`.

See [CROSS_REPOSITORY.md](./CROSS_REPOSITORY.md) for service configuration and
the shared member-session contract.

## Local development

```bash
npm install
npm run dev
```
